# Predicción de ventas — Panadería Salvador

Predicción de la demanda diaria de un producto de panadería con el ciclo completo
de MLOps: pipeline de scikit-learn, seguimiento en MLflow, registro del modelo,
despliegue como API REST y escritura de las predicciones en la base de datos.

Datathon IV — Máster en Data Analytics y Data Science, Code Space Academy.

Documentación en curso.
